# Sentinel-2 时序土地覆被变化检测流水线（CVA 自研实现）

> **在线展示：https://dingdjfjs-star.github.io/s2-cva-change-detection/ ·
> 仓库：https://github.com/dingdjfjs-star/s2-cva-change-detection**
> （本仓库由 `tools/prepare_deploy.py` 生成部署拷贝后经 api.github.com 通道发布；
> `data/` 模拟影像与 `outputs/rasters/` 中间栅格不入库，运行 `scripts/run_demo.py --force` 可重新生成）

基于 **Python + rasterio + xarray + scikit-learn** 的 Sentinel-2 时序变化检测完整流水线：
影像去云 → 年度最优值合成 → 相对辐射归一化 → **CVA 变化向量分析（核心算法纯手写）** →
阈值分割 → 伪变化过滤 → 变化栅格/矢量图斑 → 土地利用转移矩阵 → 统计报表与结果图。

> **约束声明**：未调用任何现成变化检测封装库。CVA、Otsu 阈值、连通域标记（Union-Find）、
> 二值形态学、Sobel/局部标准差纹理、medoid 合成、转移矩阵分解等核心算法均为自研实现
> （仅将 rasterio/xarray/sklearn 用于其本职：栅格 IO、张量运算、随机森林）。

## 2. 流水线架构

```

│ cloud_mask     SCL 无效类掩膜 + 膨胀 2px（兜底：4 波段规则云分数）        │
```

## 3. 原理说明

### 3.1 去云与年度最优值合成（medoid）

- **SCL 掩膜**：L2A 产品自带场景分类层，按类别码剔除（0 无数据/1 饱和/3 云影/8,9 云/10 卷云/11 雪），
  并做 **2px 形态学膨胀**——云缘半透明薄雾在 SCL 里常被低估，膨胀是最便宜的防御。
- **规则云分数兜底**（无 SCL 的栈可用）：云"蓝波段亮 + 全谱亮 + 无植被特征"，
  score = 0.5·f(蓝亮) + 0.3·f(全波段亮度) + 0.2·f(低 NDVI)。能力边界：不识别云影。
- **medoid 合成**：把一年内有效观测视为光谱空间中的点集，取到逐波段中位数欧氏距离最近的**真实观测**：

  $$m_b=\mathrm{median}_t X_{t,b},\qquad t^\*=\arg\min_t\sum_b\big(X_{t,b}-m_b\big)^2,\qquad \mathrm{comp}_b=X_{t^\*,b}$$

  相比均值/中位数合成，medoid 输出的是某一景**真实观测**，波段间相关结构不被破坏（NDVI 仍然自洽）；
  对云残留离群值稳健；且隐式选择"最接近典型状态"的时相。
- **生长季窗口（关键工程决策）**：全年 medoid 会被"非生长季状态占多数"的地物拉偏
  （如水稻一年中仅 3~4 个月处于植被峰态，全年中位数落在裸地/泡田态），且两年 medoid 在
  物候抖动下会在不同物候态之间**跳变**，制造大面积伪变化。限定 DOY∈[150,260] 后
  medoid 落在稳定的生长旺季平台，年际可比性显著提升——这是本演示调参过程中
  用真值评估实打实验证过的结论（见 §4）。

### 3.2 相对辐射归一化（PIF 迭代回归）

两期影像的大气/传感器状态差异会造成整体辐射漂移，让 CVA 幅度系统性抬升。
逐波段做稳健线性回归 y1 ≈ a·y2 + b（y2' = a·y2 + b 拉回 y1 辐射域），并用**迭代残差收紧**
构造伪不变特征（PIF）：先全像元拟合 → 剔除 |残差|>2σ → 重拟合，重复 3 轮。
直觉：两年都没变的地物才服从一致的辐射关系，变化像元是回归中的离群点。
演示场景拟合 R²≈0.99，PIF 占比 50~71%。

### 3.3 CVA 变化向量分析（核心，自研）

对两期同波段数合成影像逐像元构造变化向量 **ΔX = X2 − X1 ∈ R^C**：

- **模长** ‖ΔX‖ = sqrt(Σc wc·Δbc²) → 变化强度（是否变、多剧烈），支持波段权重；
- **方向** ΔX/‖ΔX‖ → 变化性质（怎么变）。

CVA 的根本优势是**不预设变化类型**：任何方向的光谱变化都会体现在模长上，
"检测"（模长阈值）与"定性"（方向/分类 from→to）解耦。相比单波段差值或指数差值
（只对特定方向敏感），CVA 对亮化、绿化、变干、水体消长等各类转换同等敏感。
NaN 语义贯穿（任一参与波段缺失 → 模长 NaN），nodata 不会伪装成"无变化"。

### 3.4 阈值分割（自研 Otsu）

幅度直方图典型形态是"单峰主体（未变化）+ 低矮长尾（变化）"。Otsu 遍历所有切割点
最小化类内方差 σw²(t)=ω0σ0²+ω1σ1²（等价于最大化类间方差），O(n_bins) 实现。
另提供分位数（变化占比极小 <1% 时更稳）与均值+2σ 两策略，配置一行切换；
带下限保护（反射率域 0.03），防止把传感器噪声当变化。

### 3.5 伪变化过滤（自研，五道工序）

伪变化来源：物候年际错位、大气残留、**配准误差**、传感器噪声。共同特征：
**小、碎、条带状、孤立、发生在高纹理边缘**。流水线依次执行：

| 工序 | 判据 | 针对的伪变化 |
|---|---|---|
| 形态学开运算 | 3×3 腐蚀后再膨胀 | 配准残差的 1~2px 边缘条带（演示中贡献剔除 2186 px，占伪变化 97%） |
| 形态学闭运算 | 3×3 膨胀后再腐蚀 | 真实图斑内部的碎缝（避免真实图斑被拆碎） |
| R1 面积硬阈值 | 图斑 ≥ 6px（600m²） | 椒盐噪声、孤立高幅度像元 |
| R2 空间一致性 | 邻域同类占比 ≥ 0.55 | 孤立/离散图斑；大图斑（≥60px）豁免 |
| R3 最小实心宽度 | 须含 3×3 实心核（一次腐蚀后非空） | 细长条带——**不受面积豁免**：1px×300px 的条带面积再大也不可能是可信地类转换 |
| R4 纹理约束 | 图斑内 NIR 局部 σ ≤ 0.06 | 发生在高纹理边缘的小图斑（配准/物候噪声）；大图斑豁免 |

其中 R2 的"邻域同类占比"= 图斑内像元的 8 邻域同图斑比例之均值（spatial coherence，
孤立点=0、细线≈0.25、成片图斑≈0.8+），R3 等价于对每个图斑做一次腐蚀非空检验，
两者都是手写向量化实现（np.roll/bincout），无任何现成分割库。

### 3.6 分类与转移矩阵（sklearn 随机森林）

- 特征 = 4 波段 + NDVI + 亮度（6 维）；两期**独立训练**（辐射域不同）；
  OOBAccuracy 报告泛化性能；3×3 众数滤波压制椒盐误分（手写）。
- **转移矩阵** T[i,j] = 基期类 i → 目标期类 j 像元数，并做标准分解（Pontius 口径）：

  损失 Loss = 初始面积 − 持久面积；增益 Gain = 终止面积 − 持久面积；
  **净变化 Net = |终 − 初|；交换变化 Swap = 2·min(Loss, Gain)**。

  交换变化刻画净变化看不见的"空间换位"（A 处耕地→林地、B 处林地→耕地，净≈0 但扰动双份）
  ——这是只对比两期面积统计的常见盲区。
- 另输出 **CVA 确认转移矩阵**（仅变化检测确认的像元内统计），与全域矩阵互为校核。

## 4. 实验结果与结论（演示场景，seed=20260829）

场景：400×400 px @10m（4×4 km），36 时相/年 × 2 年，真值变化 10,932 px（6.8%），5 处事件。

| 环节 | 结果 |
|---|---|
| 去云与合成 | 平均无效观测 27.2%（2023）/ 19.8%（2024）；生长季窗口内有效像元 99.7%/100% |
| 辐射归一化 | 4 波段 R² 0.992~0.998，PIF 占比 50~71%，a∈[0.95,0.99] |
| CVA + Otsu | 阈值 0.1624；原始变化 8.88%（含配准条带） |
| 伪变化过滤 | 形态学剥除 2,186 px（条带）+ 规则剔除 7 图斑/74 px；图斑 15→8 个；变化占比 8.88%→7.47% |
| 随机森林 | OOB 0.988 / 0.985；变化区 from/to 与真值一致率 99% / 95% |
| **对照真值** | **召回率 98.7%，精确率 90.3%，F1 94.3%**（FP 残留 1,156 px = 边界密集区粘连簇） |
| 分事件召回 | 采伐 99.0% / 厂房 96.9% / 围垦 100% / 开垦 99.1% / 撂荒 97.2% |

**实验结论（方法论层面，比指标更有价值）：**

1. **合成策略决定 CVA 上限**：全年合成时水稻类 medoid 在物候态间跳变，
   耕→耕伪变化幅度 P50 达 0.145（与真实变化同量级，阈值无解，精确率仅 24%）；
   换生长季窗口后未变化像元 P99 从 0.19 降至 0.10，同一套阈值算法精确率升至 90%+。
   即：**伪变化治理的大头在合成环节，而不是过滤环节**。
2. **配准残差是条带状伪变化的第一大来源**：1px 错位让所有高对比边缘产生"变化"条带
   （演示中占伪变化像元的 ~97%）。形态学开运算 + R3 实心宽度规则（不受面积豁免）
   是针对性解法；更根本的解法是检测前精配准（本流水线的已知限制，见 §6）。
3. **阈值方法要与服务对象匹配**：Otsu 在"变化占比 5~10%、双峰可分"时表现好；
   变化占比 <1% 时应切换分位数法。幅度直方图的双峰分离度（报告中输出）可作为
   自动选策略的依据。
4. **转移矩阵要配合交换变化看**：演示中耕地净变化 +23.4 ha，但交换变化高达 88.5 ha——
   只看净变化会严重低估真实扰动强度。

结果图（`outputs/figures/`）：
`fig1` 总体概览（两期假彩色/幅度/阈值直方图/过滤前后）· `fig2` 变化分布图（按转移类型着色）
· `fig3` 转移矩阵热力图 + 变化分解 · `fig4` 伪变化过滤三联图 · `fig5` 变化向量方向指纹。

## 5. 优缺点分析

**优点**

1. **核心算法全自研、可逐行讲解**：CVA/Otsu/连通域/形态学/纹理/medoid/矩阵分解均为手写，
   无黑盒；测试对拍（并查集 vs BFS 洪泛）保证正确性。
2. **工程闭环完整**：清单驱动的数据接入（manifest 解耦数据格式）、NaN 语义贯穿、
   nodata 落盘、GeoJSON 矢量输出、Markdown 报表 + CSV 明细 + 5 张图一键产出。
3. **真值可评估**：演示数据自带真值与 5 处事件，召回/精确/分事件召回全部量化，
   参数改动的影响可复现、可归因。
4. **模块可替换**：阈值三策略、云掩膜双路径、分类器可关（无样本时跳过转移矩阵），
   配置驱动。

**缺点 / 已知限制**

1. **配准残差未在流水线内处理**：演示中残留 1,156 px FP 即来源于边界密集区的粘连簇；
   生产上应先做精配准（如 AROSICS/相位相关），或直接接入本地化配准产品。
2. **双时相 CVA 的固有局限**：只回答"两期之间变没变"，回答不了"何时变、怎么渐变"——
   需要 CVA 时序化（逐窗口滑窗）或转向 CCDC/BFAST 类时序分解方法。
3. **阈值法对"渐变/低幅度变化"不敏感**（如植被退化早期），Otsu 倾向保守；
   分类误差会传入转移矩阵（演示中 from/to 一致率 95~99%，真实场景通常更低）。
4. **4 波段（10m）信息量有限**：无 SWIR（B11/B12）时建设/裸地/烧痕的区分能力下降，
   云影与水体易混；接入 20m 波段重采样后可显著改善。
5. 纯 Python 连通域标记在千万像元级场景会慢（O(N) 但常数大），届时可只对
   变化候选区做标记（当前实现已是全图扫描）。

## 6. 面试话术要点

**30 秒版本**

> "我做了一套 Sentinel-2 时序变化检测流水线：两期影像各自去云、生长季窗口内做
> medoid 年度合成，PIF 迭代回归做辐射归一化，然后用手写的 CVA 算变化向量的模长和方向，
> Otsu 自动阈值，再用形态学加四条空间规则过滤伪变化，最后矢量化图斑、用随机森林分类
> 结果构建转移矩阵并做净变化/交换变化分解。在带真值的模拟场景上 F1 94%，
> 五处人工变化事件全部 97% 以上检出。"

**2 分钟版本（补方法论细节）**

在 30 秒版基础上，按"**为什么这么做**"展开三个亮点：
① medoid 而非均值合成——保持光谱自洽且抗云；生长季窗口的必要性（水稻全年 medoid 跳变问题，
用真值评估定位并用数据说明）；② CVA 检测与定性解耦——模长阈值解决"变没变"，
方向+分类解决"怎么变"，二者互校（全域转移矩阵 vs CVA 确认矩阵）；
③ 伪变化过滤的分层设计——形态学治条带、面积治椒盐、一致性/实心宽度治碎片、
纹理治边缘噪声，且每条规则的豁免逻辑（大图斑豁免、形状规则不豁免）都有明确理由。

**高频追问与回答**

- *为什么不用现成库（如 eo-learn/pychange/RSGISLib）？*
  約束要求自研；且 CVA 本质只有十几行数学，自研才能把波段权重、NaN 语义、
  阈值策略、过滤规则做成可解释的配置项，也才能在面试中逐行讲清。
- *Otsu 失效怎么办？*
  变化占比 <1% 或直方图单峰时 Otsu 失准——我实现了分离度指标（类间/总体方差比），
  可据此自动降级到分位数法；也可以对幅度做正态拟合用均值+2σ。
- *怎么区分"水体变化"和"云影"？*
  云影在 SCL 里是类 3，先于 CVA 被掩膜；无 SCL 时用多时相一致性补偿
  （云影不会在两年 medoid 中稳定存在）。这是 4 波段栈的已知难点，SWIR 有帮助。
- *精度评估怎么做的？*
  演示数据带真值：像元级召回/精确 + 分事件召回 + 分类一致率三级评估；
  真实场景则建议分层随机采样做混淆矩阵（样本量按类别面积比例分配）。
- *如果区域很大怎么办？*
  分块流式处理（rasterio window 读取）；连通域标记改为对候选区局部执行；
  medoid 的 xarray 运算按块做。当前 400×400 端到端 6 秒，瓶颈不在计算。
- *交换变化是什么，为什么要看？*
  Swap = 2·min(损失, 增益)，刻画"空间换位"；净变化可能近零而扰动巨大，
  只看面积对比会低估变化强度（Pontius 土地变化科学标准分解）。

## 7. 接入真实 Sentinel-2 数据

1. 准备数据：Copernicus Data Space 下载 L2A（或用 GEE/CDSE 导出），
   整理为**每时相一个多波段栈**（B02/B03/B04/B08，float32 反射率 0~1，
   建议重采样到统一 10m 格网）+ 可选 SCL 波段栈。
2. 生成清单：`python tools/build_manifest.py --dir <目录> --out manifest.json`，
   自动识别 `YYYYMMDD.tif`（多波段栈）或 `YYYYMMDD_B0X.tif`（分波段）两种命名，
   坐标系/transform/nodata 自动取自首景。
3. 复制 `config.sample.json` 为 `config.json`，改 `manifest_path`、`year1/year2`、
   `samples_csv`（训练样本：year,col,row,label 四列 CSV，每期每类建议 ≥80 点）、
   `composite_doy_range`（按研究区物候设窗口，如华北冬小麦 (60,150)+(210,300) 双窗口
   需改代码为多窗口）、输出路径后运行 `scripts/run_pipeline.py --config config.json`。
4. 无训练样本时流水线自动跳过分类与转移矩阵（CVA 检测、图斑、报表照常输出）。
